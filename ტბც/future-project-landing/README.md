# Formshift

A polished, responsive landing page for a fictional digital product workspace. This project demonstrates a modern startup-style website built with clear, beginner-friendly HTML, CSS, and JavaScript.

## Features

- Responsive navigation with an animated, keyboard-friendly mobile menu
- Product-inspired hero visual created entirely with CSS
- About section with project highlights
- Three feature cards in a consistent design system
- Accessible contact form with client-side validation and success feedback
- Responsive layouts, visible focus states, and reduced-motion support
- No external libraries, image downloads, build tools, or backend services

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a browser, or open the project folder in Visual Studio Code and use the Live Server extension.

The page uses relative asset paths and works without a package manager or build step.

## Responsive Design

The layout adapts for desktop, laptop, tablet, and mobile screens. The mobile navigation collapses into a menu button, and the feature cards stack on small screens.

## GitHub Pages

This static site can be hosted on GitHub Pages:

1. Push the project to a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. When the deployment completes, open the URL shown in the Pages settings.
